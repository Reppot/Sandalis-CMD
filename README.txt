# ⚔️ SINDARIS LOGISTICS OVERWATCH CONTROL TERMINAL (Sandalis-CMD)

**Официальный терминал мониторинга и контроля логистических цепочек клана SINDARIS в Foxhole.** Высокотехнологичный тактический HUD-интерфейс, спроектированный для мгновенного отслеживания деспавна фронтовых складов, автоматического парсинга отчетов сканера и координации снабжения регионов.

---

## 📟 ОСНОВНЫЕ ТАКТИЧЕСКИЕ ВОЗМОЖНОСТИ

### 🖥️ Раздел 1: Операции Снабжения
* **Автоматический Бесшовный Мониторинг:** Встроенный фоновый движок каждую секунду проверяет файл `stockpile.txt` вашего игрового сканера. Склад обновляется на лету в реальном времени, а все нулевые позиции намертво вырезаются из списков.
* **Интерактивный Конструктор Заказов:** Быстрый поиск припасов через встроенную поисковую матрицу с тактическим сдвигом элементов при наведении мыши. Добавление ящиков в один клик.
* **Глубокий Мультиэкспорт:** Выгрузка рапортов и накладных в форматы `TXT`, `XLSX` (Excel), а также графическая нарезка бланков в `PNG`.
* **Fast Share:** Функция мгновенного копирования первой страницы графического бланка напрямую в буфер обмена для отправки в Discord через `Ctrl + V`.

### ⏳ Раздел 2: Матрица Таймеров Деспавна
* **Ранжирование по Критичности:** Склады с минимальным временем жизни автоматически летят на самый верх списка. 
* **Информационный Счётчик Рисков (Threat Counter):** Живой ежесекундный подсчет зон по уровням угрозы (`🚨 КРИТИЧЕСКИ < 1ч`, `⚠️ ВНИМАНИЕ < 24ч`, `✅ В БЕЗОПАСНОСТИ > 1д`).
* **Канал Связи и Логи истории:** Модальное окно управления позволяет вручную выставлять время удержания в Днях, Часах и Минутах, фиксируя каждое изменение в текстовый бортовой журнал базы.

### 🔔 Сквозной Глобальный Конвейер Алертов
* **60 FPS Бегущая строка:** Монолитный непрерывный поток информации по самому верху экрана, работающий на векторных шрифтах Windows ClearType без пауз и микрофризов.
* **Двухцветное кодирование:** Критические сроки баз горят неоновым оранжево-красным пламенем, а редкие случайные радиоперехваты и приказы штаба (`TACTICAL_CUSTOM_PHRASES`) выплывают сочным зеленым цветом.

---

## 🎨 ТАКТИЧЕСКИЙ ДИЗАЙН-ПАК «DESERT OVERDRIVE»

Интерфейс поддерживает мгновенное переключение глобальных стилей оформления на лету с помощью кнопки **`🌓 ТЕМА TERMINAL`** в самом низу выездного сайдбара:
* **Режим «ДЕНЬ» (Desert Khaki Theme):** Брутальная светлая песочно-армейская тема, стилизованная под полевой защищенный планшет. Идеальна для высокой читаемости при дневном свете.
* **Режим «НОЧЬ» (Cyberpunk Theme):** Фирменный глубокий графитово-черный интерфейс с яркой неоновой лаймовой подсветкой элементов. Снижает нагрузку на глаза во время ночных штурмов.

---

## 🗂 СТРУКТУРА ПАПОК РЕСУРСОВ (`scr/`)

Для полной активации графического HUD-движка внутри папки проекта должна быть создана директория **`scr/`**, содержащая следующие ассеты:
1. `clan-logo.png` — герб клана **SINDARIS** (автоматически центрируется в верхушке бокового меню).
2. `card-bg.jpg` — прямоугольная серая рамка на темном фоне (накладывается как текстура на карточки таймеров).
3. `gray-background.jpg` — тактическая подложка с черным мазком кисти (используется Pillow при генерации PNG-бланков).

## 🏃‍♂️ ИНСТРУКЦИЯ ПО ПЕРВОМУ ЗАПУСКУ

Для отладки, кастомизации и работы софта в реальном времени **не нужно тратить время на долгие билды PyInstaller**. Программа запускается напрямую за 1 секунду.

1. Откройте командную строку Windows (`cmd`) в корневой папке проекта.
2. Установите необходимые библиотеки:
   ```cmd
   pip install PySide6 pandas openpyxl pillow
   ```
3. Запустите терминал одной командой:
   ```cmd
   python gui_app.py
   ```

## 🛠 РЕДАКТИРОВАНИЕ И ПРИКАЗЫ ШТАБА

Вы можете легко изменить список случайных фраз, которые транслируются бойцам в бегущей строке. Для этого откройте файл `gui_app.py`, найдите в самом верху массив `TACTICAL_CUSTOM_PHRASES` и впишите туда любые новые текстовые строки:

```python
TACTICAL_CUSTOM_PHRASES = [
    "[ШТАБ SINDARIS]: Ваш приказ или лозунг здесь!",
    "[ИНТЕНДАНТСТВО]: Еще одна крутая фраза для логистов..."
]
```
