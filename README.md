# ⚔ SINDARIS LOGISTICS OVERWATCH CONTROL TERMINAL (Sandalis-CMD)

[![License: MIT](https://shields.io)](LICENSE)
![Platform](https://shields.io)
![Python](https://shields.io)
![Status](https://shields.io)

Высокотехнологичный тактический HUD-интерфейс, спроектированный для мгновенного отслеживания деспавна фронтовых складов, автоматического парсинга отчетов сканера, контроля поставок поштучно/в ящиках и координации снабжения регионов. 

Программа полностью переведена на **монолитный статичный движок отображения плоских PNG-иконок**, что позволило снизить нагрузку на процессор до нуля, обеспечить стабильные **60 FPS** для конвейера алертов и устранить любые микрофризы при развертывании терминала на весь экран.

## 1. Установка и запуск «с нуля»

> Данный раздел разработан штабом для бойцов и логистов клана, которые ранее **не работали с программированием** и запускают консольные скрипты впервые. Повторяйте шаги в строгой последовательности.

### Шаг 1 — Развертывание среды Python
1. Перейдите на официальный портал [python.org/downloads](https://python.org) и загрузите актуальный дистрибутив Python для Windows.
2. Запустите инсталлятор.
3. **⚠️ КРИТИЧЕСКИ ВАЖНО:** На самом первом экране установщика внизу окна поставьте галочку **"Add python.exe to PATH"**. Без этого флага операционная система не сможет распознать команды запуска терминала.
4. Нажмите **"Install Now"** и завершите процесс.
5. Для верификации откройте командную строку Windows (`Win + R` -> введите `cmd` -> `Enter`) и выполните команду:
   ```cmd
   python --version
   ```
   Если консоль вернула версию (например, `Python 3.12.4`), среда готова.

### Шаг 2 — Установка зависимостей проекта
1. Открой командную строку и перейди в корневую директорию вашего терминала снабжения:
   ```cmd
   cd /d D:\Games\foxhole-stockpiles-main
   ```
2. Установите библиотеки графического интерфейса, обработки таблиц данных и работы с изображениями одной командой:
   ```cmd
   pip install PySide6 pandas openpyxl pillow
   ```

### Шаг 3 — Локальный запуск скрипта
1. Запуск интерактивного приложения осуществляется напрямую из корня без необходимости долгой предварительной сборки:
   ```cmd
   python gui_app.py
   ```
2. Окно консоли во время работы программы аккуратно сворачивается. При закрытии консоли работа терминала Sindaris HQ завершается.
## 2. Полный разбор тактических возможностей

### 2.1. Раздел «Заказы» (Операции Снабжения)
Основной рабочий узел интенданта, предназначенный для оперативного формирования списков снабжения и парсинга логов.

* **Интерактивный Монитор Текущих Запасов:** Модуль автоматически отслеживает изменения в файле импорта, налету подгружая данные. Позиции с нулевым остатком автоматически вырезаются из интерфейса, чтобы не засорять экран.
* **Умная Двухрежимная Матрица Предметов:** Добавление ресурсов в заказ поддерживает гибкое разделение единиц измерения. Предметы могут измеряться как стандартными **Автоматическими Ящиками (ящ.)**, так и **Штуками (шт.)**. Логика конструктора полностью защищена от ошибок распаковки некорректных типов данных.
* **Интерактивный Поисковый Фильтр:** Позволяет мгновенно находить нужные типы вооружения и припасов в огромной таблице матрицы. Поиск снабжен графической иконкой-маркером (`image_1TEVG0.png`) для интуитивного Sci-Fi восприятия.
* **Быстрый Графический Импорт:** Над левой таблицей интегрирована панель быстрого добавления данных в один клик. Фиолетовая кнопка-иконка (`json.png`) отвечает за загрузку сырых файлов с внешних сканеров, а зеленая кнопка (`log-file.png`) осуществляет мгновенный парсинг скопированного текста напрямую из буфера обмена.
* **Компактная Очистка Паллет:** Справа от выпадающего списка размещена вертикальная графическая кнопка полной очистки рапорта с иконкой паллета и крестика (`image_MXUXFY.png`). Она защищена от затирания глобальным QSS-кодом и сбрасывает текущий заказ мгновенно без перезапуска окон.
* **Универсальный Экспорт Отчетов:** Внизу обеих панелей развернуты графические строки экспорта, содержащие подписи и иконки форматов (`image_x4lfy4.png`, `image_LLScL9.png`, `image_KslIXG.png`). Система поддерживает:
  - Выгрузку чистого текстового рапорта (`TXT`).
  - Формирование структурированной таблицы снабжения Excel (`XLSX`) с отдельной колонкой «Ед. изм.».
  - Рендеринг бланка на тактическом фоне в картинку (`PNG`).
  - Быстрое копирование бланка рапорта в буфер для отправки в Discord (`Ctrl + V`).

### 2.2. Раздел «Таймеры» (Матрица Складов)
Специализированный экран координации, предназначенный для предотвращения деспавна («сгорания») фронтовых запасов.

* **Автоматическое Ранжирование Рисков:** Склады и опорные пункты с минимальным временем жизни автоматически выталкиваются на самый верх таблицы, перетягивая приоритет логистов на себя.
* **Информационный Счётчик Угроз (Threat Counter):** Живой ежесекундный подсчет зон по уровням критичности (`🚨 КРИТИЧЕСКИ < 1ч`, `⚠ ВНИМАНИЕ < 24ч`, `✅ В БЕЗОПАСНОСТИ > 1д`).
* **Управление Удержанием:** Интерактивное модальное окно позволяет логистам вручную продлевать время жизни складов в днях, часах и минутах, фиксируя каждое действие в бортовой журнал базы.

### 2.3. Раздел «Обучение» (Штаб Клана)
Третий навигационный узел, спроектированный для подготовки молодых водителей и логистов клана SINDARIS.
* **Статичная Центрированная Эмблема:** Поскольку любые тяжелые GIF-анимации строго запрещены для исключения лагов, в центре экрана размещено высококачественное плоское изображение военной палатки штаба (`image_cU6Sxy.png`), отмасштабированное по технологии Smooth Transformation под большие мониторы.
* **Информационная Заглушка:** Пока материалы находятся в разработке штаба, экран выводит контрастное текстовое уведомление, полностью адаптированное под светлую и темную темы приложения.

### 2.4. Сквозной Глобальный Конвейер Алертов
* **60 FPS Бегущая Строка:** Непрерывный поток информации в самом верху экрана, транслирующий критические таймеры баз и приказы интендантства (`TACTICAL_CUSTOM_PHRASES`). Кэширование `DeviceCoordinateCache` полностью разгрузило процессор, обеспечивая идеальную плавность хода текста на весь экран.

## 4. Конфигурация Git и правила обновления репозитория

Чтобы исключить попадание бэкапов (`.bak`), временных архивов (`.rar`), логов отладки и лишних служебных папок Python в публичный репозиторий GitHub `Sandalis-CMD`, настроен строгий белый список через файл конфигурации `.gitignore`.

### 4.1. Содержимое файла `.gitignore`
В корне проекта находится файл `.gitignore` со следующим содержимым:
```text
*
!gui_app.py
!gui_app.spec
!item_codes.py
!Sandalis-Read-me.md
!scr/
!scr/**
!dist/
!dist/**
```

### 4.2. Консольный протокол точечного пуша
Для отправки обновления на GitHub выполните в командной строке `cmd` последовательно следующие тактические команды:
```cmd
cd /d D:\Games\foxhole-stockpiles-main
git add .
git commit -m "Фикс интерфейса: исправлено смещение сетки, настроено отображение иконок сайдбара и чистка QSS"
git push origin main
```
*Благодаря настроенному фильтру, Git проигнорирует весь мусор в папке и зальет только строго разрешенные файлы и каталоги.*

## 5. Развернутый FAQ по решению проблем

#### Почему пропадали иконки на кнопках сайдбара при сворачивании меню или смене темы?
Это происходило из-за конфликта глобальных QSS-стилей. Команды `background-color` стирали внутренние параметры отображения `QIcon`. Проблема решена путем переноса масштабирования на уровень Python через метод `btn.setIconSize(QSize(36, 36))` и явной защиты стилей кнопок через инлайновые вызовы.

#### Из-за чего возникала ошибка `UnboundLocalError: cannot access local variable 'QIcon'`?
Внутри циклов экспорта находились скрытые локальные импорты вида `from PySide6.QtGui import QIcon`. В Python наличие импорта внутри функции переопределяет видимость переменной во всем методе с первой строки. Решено полной зачисткой локальных импортов и вынесением `QIcon` на глобальный уровень в строку №10 заголовка файла.

#### Почему левая таблица склада смещалась вправо и заезжала под картинку?
В коде горизонтального макета `app_layout` для контейнера страниц `self.pages_container` был прописан жесткий левый отступ в `95px`, а сам сайдбар выводился как независимый плавающий оверлей. Код полностью переписан: сайдбар возвращен в общий аппаратный макет `QHBoxLayout` на позицию №1 (слева), отступы сброшены в `0`, а ручные функции пересчета `setGeometry` удалены.

#### Почему кнопки нижнего экспорта правой стороны двоились (выводилось 8 кнопок вместо 4)?
В самом низу метода `setup_workspace(self)` правого макета `r_btn_grid` по ошибке находились два одинаковых цикла генерации кнопок подряд (один старый текстовый и один новый графический `r_export_formats`). Лишний цикл полностью удален, кнопки выстроены в один чистый ряд с инлайновой фиксацией белого цвета букв.

#### Почему тяжелые GIF-анимации на кнопках сайдбара и в центре экрана полностью запрещены?
Сигналы перерисовки кадров `frameChanged` приводили к попиксельному пересчету прозрачности `rgba` больших полупрозрачных панелей. При развертывании приложения во весь экран (Full HD / 2K) это вызывало лаги всего интерфейса и дерганье бегущей строки. Приложение переведено на статичные PNG-картинки, а для бегущей строки включен аппаратный кэш графики `DeviceCoordinateCache`.
